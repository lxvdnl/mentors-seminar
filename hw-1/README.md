# Домашнее задание 1. Базовые конструкции Go

Каждое задание лежит в отдельной папке.

| Папка | Задание |
|---|---|
| `task01-calculator` | Калькулятор с проверкой деления на ноль |
| `task02-number-analysis` | Анализ числа |
| `task03-sum-average` | Сумма и среднее от 1 до N |
| `task04-multiplication-table` | Таблица умножения через функцию `printTable(n)` |
| `task05-min-max` | Максимум и минимум из N чисел |
| `task06-sign-count` | Количество положительных, отрицательных чисел и нулей |
| `task07-filtered-sum` | Сумма чётных чисел от 1 до N, которые делятся на 3 |
| `task08-prime` | Проверка простого числа `isPrime(n int) bool` |
| `task09-atm` | Мини-банкомат |
| `task10-statistics` | Статистика последовательности |

## Запуск

```bash
go run ./task01-calculator
```

## Тесты

```bash
go test ./...
```
